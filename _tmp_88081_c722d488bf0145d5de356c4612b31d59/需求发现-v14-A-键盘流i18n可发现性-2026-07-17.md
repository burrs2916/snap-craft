## v1-v13 真正漏掉的 5 条维度总结

1. **键盘流的"导航维度"完全空白**——v1-v13 只列了"5 个全局快捷键 + 6 个应用内快捷键"，但**截图后→标注→AI→导出** 4 个核心界面完全没有 **↑↓ 选中 / Enter 打开 / Delete 删除 / Tab 焦点** 的列表级键盘流，**84% 列表只支持鼠标点击**（见 grep 结果：history-item 只绑 Enter/Space，不绑 ↑↓/Delete；AIPanel preset/conversation 列表零 onKeyDown）。
2. **i18n 三盲区**——(a) **`t()` 在 useState/useMemo 初始化时会被冻**（eg. `useState(loadOcrHist())` 的 toast 字符串在 zh 切换 en 后**仍是中文**，因为 `t()` 是在 mount 时调一次），(b) **复数 / 日期 / 数字 / 文件大小格式无本地化**（grep 出 12 处 `toLocaleString()` 不传 locale，会跟随系统但**无 zh/en 切换联动**），(c) **跨窗口 i18n 同步只对 `snapcraft:lang-changed` 事件广播做了**，**但 AI 独立窗加载时机晚于主窗事件时丢消息**（listen 在 mount 后才注册，主窗 setLang 之后才打开 AI 窗，事件没听到，AI 窗 UI 仍是旧语言）。
3. **可发现性"下一步去哪" 0 引导**——v13-C19/C20 提了 tour 但待落地，本次新发现**4 个"完成态"无引导按钮**：截图保存后、AI 对话完成、OCR 完成、6 格式导出后——4 个最常见的"刚发生了什么"瞬间，**0 个 "Open with / Reveal in Finder / Copy / Apply" 引导**，用户每次都靠肌肉记忆。
4. **macOS 系统快捷键正面冲突**——`src-tauri/src/lib.rs:122-127` 同时注册了 `⌘⇧S` / `⌘⇧1` / `⌘⇧2` / `⌘⇧3` / `⌘⇧4`，其中 `⌘⇧4` **就是 macOS 原生区域截图**（macOS 13+ 默认 `⌘⇧4` 触发 Screenshot app 的区域选择），`⌘⇧S` 在某些 macOS 版本被 Safari/Finder 占用，**5 个全局快捷键里至少 2 个与系统硬冲突**，需让用户自定义或降级。
5. **触屏 / 鼠标手势 / 滚轮 三轴 0 支持**——`AnnotationCanvas.tsx:1596` 起的 `handleMouseDown` 无 `onTouchStart` 对应，编辑器标注**触屏不可用**；`onWheel` 全工程 0 处，**编辑器不支持滚轮缩放、Pin 窗不支持滚轮切换 Pin 列表、历史不支持拖拽多选**——macOS 笔记本触控板 + 触屏（iPad 副屏）用户完全用不到。
